# Trip Twin OSM fixtures

Recorded responses to `buildTwinQuery()` (src/operations/tripTwin/twinData.js) for the three prototype hotels, made by `scripts/capture-trip-twin-osm.mjs`. Used by unit tests and by `twin.html?osm=fixture` so demos do not depend on public Overpass capacity.

Map data © OpenStreetMap contributors, available under the Open Database License (ODbL 1.0): https://www.openstreetmap.org/copyright. Any page that renders this data must show that attribution.

These files are development fixtures. They are not bundled into the app build.
