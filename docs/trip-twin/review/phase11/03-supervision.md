# Phase 11 review: supervision, delegation, reversibility, trust

**Verdict.** Phase 11 keeps the phase 10 control model, and the new motion has sound limits: Reduce motion wins, drift waits 60 s, and any input stops it. The problem is that motion state shows only as a 20 px "· drifting" at the end of the wall chip and appears nowhere on the remote. The remote preview also draws a LIVE badge and role over pictures that are absent or 17 s old, and it leaves out pin, local view and drift. An open report on another trip on watch reaches S6 and nothing else. Nothing in the stills rises to P0. Before the demo, land these P1s: incident and stale states that stop all motion, an honest preview strip, real view-only controls, scoped setup tokens, a visible "return all" path and a session log.

Reviewed from stills and documents only. Facts about live behaviour are taken from the brief. Where a still cannot show a state, the finding says what to check.

## Assistant layer: three rules

1. **Every sentence traces to a row, and the summary dies with its data.** The summary is generated only from the sample snapshot the walls are showing. Each claim links to the count, row or alert it came from. The header reads "Generated summary · sample data · 21:32 tick · checked 21:33". It regenerates only on a data tick. When the link or feed is stale, or the summary's numbers differ from the wall's own numbers, it hides and reads "Summary paused: data stale" (a test checks number equality).
2. **It describes and never directs or reassures.** It uses the product's own uncertainty words (likely, possible, not verified, not current, not located) and never raises certainty. It passes the same wording-rule check as every other string (no reassurance words, no certain forecasts), and it never recommends move or shelter. Those decisions belong to the operator and the official issuer, and official text is quoted verbatim with its issuer and age.
3. **It has no write path and no motion.** It cannot push, acknowledge, change tiers or move a camera. It appears on S3 below the incident board in a box marked as generated, and only after the controller pushes it there (a normal push with Undo). Every version shown is logged with its input tick and a hash, so anyone can reconstruct afterwards what the room was told.
