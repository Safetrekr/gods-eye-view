# Phase 12 review: trust, provenance and supervision ("See it coming")

**Verdict.** The approach line is honest in its long form: it names the band, the distance, the motion, "on this track", the source and the frame time, and every simulated element says SIMULATED. Two P0s block use in a live room: the arrival time is counted from the radar frame and not from now (5 to 13 min late in the US; in Europe a core that arrived 40 min ago reads "in about 25 min"), and the demo storm replaces the real radar and lightning on every wall with no end time, no log, and no reset by "Return all to Live". Below those, the short forms (chip, remote pill, lens strip) drop source, age or SIM, walls and the remote compute separate nowcasts that already disagree in the stills, lightning inside the 30-minute rule never reaches the walls, and the room cannot acknowledge an approach.

Reviewed from the stills and the code (`twinNowcast.js`, `twinNowcastLoad.js`, `page.js` phase 12, `twinScreen.js`, `remote/remote.js`, `remote/stations.js`, `twinSession.js`). Nothing was changed except this file.
