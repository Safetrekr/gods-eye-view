# Trip Twin — planning, reviews and decisions

Prototype: `twin.html` (run `npx vite --config vite.twin.config.js`), code in `src/operations/tripTwin/` and `server/tripTwin/`.

- `00-CONTEXT.md` … `07-production-delta.md` — specialist plans (scenarios, layers, architecture, screens, motion, vocabulary, production delta).
- `PROJECT-PLAN.md`, `ROUND-2.md`, `PHASE-*-PLAN.md` — phase plans and decisions.
- `WEATHER-SOURCES.md`, `WEATHER-TIMELINE-SOURCES.md` — verified data sources and licences.
- `review/` — after every phase, four design reviews (UX, UI, supervision surface, information architecture) and the merged `00-FIX-LIST.md` with its status.
- `BACKLOG.md` — next rounds.
- `runbooks/` — operating the wall host: `deploy-mac-studio.md`, `demo-day.md`, `re-pair.md`, `break-glass.md`, `unknown-device.md` (Phase CF K2). The relay keeps the wall in `~/Library/Application Support/SafeTrekr/trip-twin/` (or `TRIP_TWIN_DATA_DIR`).

Review screenshots (before / after, 1600×900 and 1280×720) are kept outside the repo (about 110 MB) and are not committed.
